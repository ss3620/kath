### WowRevenue - Increase your Order Value with Product Bundles & Strategic Discount Campaigns

WowRevenue is an advanced all-in-one product bundle plugin specially crafted to boost the WooCommerce store’s revenue by showing high-converting bundle and discount offers. Its effective marketing campaigns help you start upselling and cross-selling instantly. As a result, you can enjoy better revenue without increasing the number of customers. So you don’t need to spend more on customer acquisition.

## Advanced Product Bundling Features in WowRevenue ##

WowRevenue gives you flexible controls for building and displaying product bundle offers based on your store's requirements.

* **Trigger Product Selection:** Choose the product that activates and displays the bundle offer.

* **Minimum Product Quantity:** Set the minimum quantity customers need to purchase for individual bundle products.

* **Flexible Bundle Discounts:** Define discount values and choose the applicable discount type for offered products.

* **Free Shipping:** Add free shipping to supported bundle campaigns directly from the campaign builder.

* **Countdown Timer:** Add a countdown timer to time-sensitive bundle offers.

* **Animated Add to Cart:** Apply an animated Add to Cart effect to supported campaigns.

* **Campaign Scheduling:** Set a start date and time and optionally define when the bundle campaign should end.

* **Multiple Page Placements:** Control the WooCommerce pages where supported bundle campaigns appear.

* **Flexible Display Modes:** Show supported bundle offers in-page, inside a pop-up, or as a floating offer.



## Free Product bundle and Discount Campaigns in WowRevenue ##

WowRevenue includes eight campaign types in the free plugin. You can create and use these campaigns without installing WowRevenue Pro.

✅ **Normal Discount:** Apply discounts to specific products, multiple products, or selected product groups.

✅ **Bundle Discount:** Combine multiple products into a bundle and set up pricing or discounts.

✅ **Volume / Quantity Discount:** Create quantity-based pricing tiers and apply discounts based on how many items customers purchase.

✅ **Buy X Get Y:** Create offers where customers purchase qualifying products and receive another product for free or at a discounted price.

✅ **Free Shipping:** Set spending requirements for free shipping and display progress with a visual bar.

✅ **Stock Scarcity:** Display stock availability or scarcity messages for selected products.

✅ **Countdown Timer:** Add countdown timers to products with scheduled start and end times.

✅ **Next Order Coupon:** Provide customers with a coupon they can use on a future order.

## Campaigns Available in WowRevenue Pro ##

WowRevenue Pro adds four additional campaign types for creating more advanced bundle, cross-sell, cart, and spending-based offers.

⭐ **Mix and Match:** Let customers choose products from a predefined selection and create their own bundle.

⭐ **Frequently Bought Together:** Display related products together and let customers add multiple items to the cart from one offer.

⭐ **Spending Goal:** Create spending milestones with rewards such as discounts, free shipping, or free gifts.

⭐ **Double Order Plus:** Let customers increase the quantity of their cart or selected products and receive an associated discount.

== Installation ==

= Minimum Requirements =

* WordPress 6.8 or greater
* PHP version 7.4 or greater
* MySQL version 5.6 or greater

= Automatic installation =

Automatic installation is the easiest option as WordPress handles the file transfers itself and you don’t even need to leave your web browser. 

1. Go to your WordPress Plugin installation menu (Dashboard > Plugins > Add New)
2. In the search field type "Revenue" and press enter.
3. "Install Now" and then click "Active"


= Manual installation =

For Manual installation, you download our product from WordPress directory uploading it to your web-server via your FTP or CPanel application.

1. Download the plugin and unzip it
2. Using an FTP program or CPanel upload the unzipped plugin folder to your WordPress installation’s wp-content/plugins/ directory.
3. Activate the plugin from the Plugins menu (Dashboard > Plugins > Installed Plugins) within the WordPress admin.

= Upgrading =

Automatic update working great for this plugin. If you customize the plugin make sure to store a backup before update.

Sometimes because of the permalink issue during the plugin update, just go to WordPress > Settings > Permalinks and hit the ‘Save’ button.

= What's the difference between WowRevenue and WowRevenue Pro? =
WowRevenue (this plugin) is free and fully functional on its own, with eight campaign types including Product Bundles, Buy X Get Y, and Quantity/Volume Discount. [WowRevenue Pro](https://www.wowrevenue.com/) is a separate paid plugin that adds four more campaign types: Mix and Match Bundles, Frequently Bought Together, Double Order, and Spending Goal. Pro is not required to use this plugin.

== External services ==

This plugin does not contact any external server on its own. It sends no telemetry, performs no license or update check, and loads no scripts, styles, fonts or images from a remote host. Everything described below happens only after you click something in the plugin's admin screens.

= YouTube video tutorials =

Some campaign types show a "Watch Tutorial" button in the campaign builder. Clicking it opens a dialog that embeds the matching tutorial video from youtube.com. Nothing is requested from YouTube until you click that button, and the request happens as soon as the dialog opens, whether or not the video then plays.

What is sent: your browser loads the video player from youtube.com, so YouTube receives the usual information a browser sends with any request, including your IP address and browser details, along with the ID of the tutorial video. The embed sends only your site's address as the referrer, not the full admin page URL. No store, order, customer or campaign data is sent. YouTube may set cookies in your browser.

Service provided by Google. See [YouTube's Terms of Service](https://www.youtube.com/t/terms) and [Google's Privacy Policy](https://policies.google.com/privacy).

= Links to the vendor's sites =

The admin screens contain ordinary links to pages on the plugin author's sites. Nothing is loaded from them unless you click a link, and clicking one simply opens that page in your browser.

* [wowrevenue.com](https://www.wowrevenue.com/) and [wpxpo.com](https://www.wpxpo.com/): product, pricing and documentation pages, linked from "Upgrade to Pro" and the help links.
* [account.wpxpo.com](https://account.wpxpo.com/): the author's account and checkout pages, used for purchasing or renewing a WowRevenue Pro license.
* [facebook.com](https://www.facebook.com/groups/wowcommercecommunity): the user community group, linked from the plugin dashboard.

= License activation and plugin updates =

This free plugin does not contact any licensing or update server. License activation and update checks against the author's licensing server happen in the separate WowRevenue Pro plugin and are documented in that plugin's readme.
